# Phase 2B implementation plan

1. Add an opt-in internal stage range and role in `src/llama-model.h` and its internal load interface. In `src/models/qwen3moe.cpp`, retain global layer numbers and gate tensor creation by ownership. In `src/llama-model-loader.cpp` validate owned tensor completeness, account for intentionally skipped tensors and exclude unowned ranges from mmap prefetch. In `llama_model_base::load_tensors`, allocate owned contexts only and let existing local Pager registration consume only owned sources.
2. Use the same range in `llama_kv_cache::llama_kv_cache` and preserve global layer addressing. In `llama_model_qwen3moe::graph::graph` accept a suffix activation input and emit a prefix activation result. `src/llama-graph.h/.cpp` and `src/llama-context.cpp` expose the stage input/output internally and reuse graphs for matching batch, Context and output shape. Keep standard decode on the existing full range. Test the in-process two-stage handoff before a socket is introduced.
3. Add an opt-in entry point in tools/stage-worker/main.cpp for Coordinator and Worker modes, with stage-protocol.h/.cpp for frames and stage-transport.cpp for Winsock/POSIX sockets. Wire the tool in tools/CMakeLists.txt behind a build option. Start decode with one fixed token and one sequence. Define OPEN with protocol/model and shard hashes/ranges/Context, READY with session ID, STEP with monotonic request and position, shape and checked F32 length, RESULT with echoed step, status and token or diagnostic logits, and CLOSE. One request in flight. Reject ranges outside the configured split, replayed or malformed frames, incompatible shape and unexpected position. Both stages hold tentative progress until the response. Stop and discard both KV states after any ambiguous request, disconnect, timeout or compute error. Replay acknowledged tokens in a fresh session.
4. Verify on synthetic Qwen3MoE. For a fixed token stream compare prefix boundary and final logits with a single-process reference. Compare all finite outputs and Expert IDs. Assert per-process tensor/bytes inventory, local KV allocation and local Expert reads. Assert activation traffic shape/count and zero network weight transfer. Kill Worker mid-step, inject wrong shapes and duplicate positions, and check bounded termination and no KV reuse across failed sessions.
5. Add batched prefill with absolute positions and local mask construction, then run loopback followed by two isolated Windows x86-64 hosts and Windows/Linux. Record binary and model hashes, CPU ISA/float deviations, stage memory peaks, model-load ownership and link traffic. Introduce real Qwen3MoE only after per-stage budget and fixture correctness are verified.
